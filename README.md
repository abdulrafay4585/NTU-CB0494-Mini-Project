# NTU CB0494 Mini-Project

## About

This project was completed as part of the NTU CB0494 course. The project uses the Diabetes 130-US Hospitals dataset to investigate predictors of hospital readmission among diabetic patients using a binary Decision Tree Classifier.

## Project Overview

The project investigates the following research questions:

1. Using a binary classification tree, what are the top 3 predictors for predicting whether a patient aged 50 and above will be readmitted?
2. Are these predictors affected by participant attributes such as race and gender?

The analysis involved data preparation, exploratory data analysis, decision tree classification, and evaluation using metrics including accuracy, true positive rate, false positive rate, true negative rate, false negative rate, and Youden's J statistic.

## Key Finding

Across the whole dataset and demographic subgroups examined, `number_inpatient` was consistently identified as the strongest single predictor of hospital readmission.
